1. Copy [_template.md](./_template.md) to `phase-NN-<slug>.md` when starting a phase.
2. Update the index table above (Status: In progress → Complete).
3. Check off tasks in [stack-setup.md](../stack-setup.md) for that phase.
4. Link new test IDs in the phase doc when specs are implemented.
